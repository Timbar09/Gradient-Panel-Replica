# Gradient-Panel-Replica

A simple card component built with Vite and Tailwind CSS.

## Features

- Beautiful gradient header (purple → pink → red)
- Clean and modern design
- Responsive layout
- Hover effects and smooth transitions
- Built with Vite for fast development
- Styled with Tailwind CSS v4

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Timbar09/Gradient-Panel-Replica.git
cd Gradient-Panel-Replica
```

2. Install dependencies:
```bash
npm install
```

### Development

Run the development server:
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to see the card.

### Build

Build for production:
```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview

Preview the production build:
```bash
npm run preview
```
