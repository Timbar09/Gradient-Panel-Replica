# Gradient Panel Card

A simple, elegant card component built with Vite and Tailwind CSS featuring a beautiful gradient background.

![Screenshot](https://github.com/user-attachments/assets/0b806836-3455-4447-8bd1-23cf5671ba77)

## Features

- 🎨 Beautiful purple-pink-red gradient background
- 📱 Fully responsive design
- ✨ Smooth hover animations and shadows
- ⚡ Lightning-fast development with Vite
- 🎯 Utility-first styling with Tailwind CSS v4

## Technologies Used

- **Vite 7.1.7** - Next generation frontend build tool
- **Tailwind CSS 4.1.16** - Utility-first CSS framework
- **PostCSS** - CSS transformation tool

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Timbar09/Gradient-Panel-Replica.git
cd Gradient-Panel-Replica
```

2. Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173/`

### Build for Production

Create a production build:
```bash
npm run build
```

The built files will be in the `dist/` directory.

### Preview Production Build

Preview the production build locally:
```bash
npm run preview
```
